# Changelog

## 1.5.0 — 2026-11-09
- All pages now show in one scrolling view. Click any page to edit it with the current tool; the page list and page number follow as you scroll.
- Open several PDFs or images at once (choose more than one file in Open, or drag several in). They are combined into one document, or added to the document that is already open.
- Search highlights now show on every page, not only the current one.

## 1.4.3 — 2026-11-05
- The app now offers to install itself the first time it opens, with a desktop shortcut, Windows search and an Apps list entry for removal.

## 1.4.2 — 2026-11-05
- PDF Editor Pro is now open source under AGPL-3.0; the About box links to the source code.
- New installer: adds a desktop shortcut and a Start Menu entry, so the app can be found with Windows search.
- New Update button in the status bar and Help > Check for updates: downloads and installs new versions from GitHub.

## 1.4.1 — 2026-11-05
- Fixed edited text showing as empty boxes when editing a PDF that was already saved by this app.

## 1.4.0 — 2026-11-04
- New modern design: tools are now colour-coded tiles grouped by task, so all of them fit on screen without scrolling.
- Refreshed dark and light colours, with a new indigo accent.
- Added Cambo Ads copyright to the tool panel, welcome screen, status bar, About box and EXE properties.

## 1.3.1 — 2026-11-03
- Fixed "insert_text() got an unexpected keyword argument 'fontbuffer'" when editing text with the PDF's own font.

## 1.3.0 — 2026-10-23
- Edit Text: new text starts exactly where the original text started (no more shifting).
- Edit Text: spaces and hyphens are stored correctly, so copy/search work after editing.
- Option to reuse the PDF's own embedded font when it contains all needed letters.
- Saved files are smaller (only the used letters of each font are embedded).
- Version number shown in the title bar, status bar, About and EXE properties.

## 1.2.0
- English-only interface; fixed crash when the program restarted itself.

## 1.1.0
- New modern design: dark/light theme, line icons, grouped tools, contextual property bar,
  welcome screen with recent files, page thumbnail cards.

## 1.0.0
- First release: edit/add text (Khmer supported), annotations, signatures, page tools,
  merge/split, watermark, page numbers, forms, bookmarks, passwords, export, print.
